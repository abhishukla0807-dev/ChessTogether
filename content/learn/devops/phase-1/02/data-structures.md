## 1. DevOps Data Types

- Hash Maps / Dictionaries: Key-value lookups, JSON/YAML parsing, environment configs.
- Arrays / Lists: Resource inventories, server lists, pipeline stage queues.
- Trees & DAGs: Dependency graphs in Terraform, Make, and CI/CD pipelines.
