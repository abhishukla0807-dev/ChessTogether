## 1. Key Directories

- /etc: System-wide configuration files.
- /var/log: System and application log files.
- /proc & /sys: Virtual pseudo-filesystems exposing kernel parameters and process states.
- /usr/bin & /usr/local/bin: User binaries and executable utilities.
