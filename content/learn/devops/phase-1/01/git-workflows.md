## 1. Common Branching Models

- Trunk-Based Development: Engineers push frequent, small changes to main; prerequisite for high-velocity CI/CD.
- GitFlow: Feature, develop, release, and hotfix branches; suited for scheduled, packaged version releases.
- GitHub Flow: Simple feature branches merged into main via PRs with automated deployments.
