## 1. Service Models

- IaaS (Infrastructure as a Service): Virtual machines, raw networking, storage (AWS EC2, S3).
- PaaS (Platform as a Service): Managed runtime environments (Heroku, AWS Elastic Beanstalk).
- SaaS (Software as a Service): End-user software applications (Slack, Google Workspace).
